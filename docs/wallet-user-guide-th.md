# คู่มือการใช้ระบบวอลเลตและแต้มสะสม
# Wallet and Points System User Guide

## ภาพรวมระบบ (System Overview)

ระบบวอลเลตและแต้มสะสมของ Nuxnan ออกแบบมาเพื่อให้ผู้ใช้สามารถ:
- สะสมแต้มจากการใช้งานระบบ
- แปลงแต้มเป็นเงิน
- ฝากและถอนเงิน
- โอนเงินให้ผู้ใช้อื่น
- แลกรางวัลต่างๆ

---

## 1. ระบบแต้มสะสม (Points System)

### ประเภทแต้ม
- **แต้มหลัก (Primary Points/PP)**: แต้มที่ได้จากการมีส่วนร่วมในระบบ
- **แต้มโบนัส (Bonus Points)**: แต้มพิเศษจากกิจกรรมพิเศษ

### วิธีการสะสมแต้ม

#### 1.1 โพสต์และโซเชียล (Posting & Social)
| กิจกรรม | แต้มที่ได้รับ | รายละเอียด |
|---------|--------------|-----------|
| สร้างโพสต์ทั่วไป | +180 แต้ม | โพสต์ข้อความใหม่ |
| โพสต์พร้อมรูปภาพ | +240 แต้ม | โพสต์พร้อมรูปภาพ |
| รับไลค์ | +12 แต้ม/ครั้ง | เมื่อคนอื่นกดไลค์โพสต์ของคุณ |
| รับการแชร์ | +18 แต้ม/ครั้ง | เมื่อคนอื่นแชร์โพสต์ของคุณ |

#### 1.2 การเรียนรู้ (Learning)
| กิจกรรม | แต้มที่ได้รับ | รายละเอียด |
|---------|--------------|-----------|
| ทำแบบทดสอบถูก | +คะแนนที่ได้ | ตามคะแนนข้อสอบ |
| ส่งงาน | +5-20 แต้ม | ตามประเภทงาน |
| เข้าเรียนบทเรียน | +10-50 แต้ม | ตามระดับบทเรียน |

#### 1.3 กิจกรรมพิเศษ (Special Activities)
| กิจกรรม | แต้มที่ได้รับ | รายละเอียด |
|---------|--------------|-----------|
| โหวต | +points_per_vote | จาก pool ของโพล |
| ดูโฆษณา | +4% × duration | แปลงเป็นเงิน wallet |
| รับบริจาค | +240 แต้ม | ต่อครั้ง |
| Daily Login | +10-50 แต้ม | ตาม streak |

#### 1.4 Streak Bonus (โบนัสการเข้าใช้งานต่อเนื่อง)
```
วันที่ 1-3:   10 แต้ม/วัน
วันที่ 4-7:   20 แต้ม/วัน
วันที่ 8-14:  30 แต้ม/วัน
วันที่ 15-30: 50 แต้ม/วัน
วันที่ 31+:   100 แต้ม/วัน
```

#### 1.5 Level Up Bonus
- ได้รับ **100 × level** แต้ม เมื่อขึ้นเลเวล

## 3. ระบบวอลเลต (Wallet System)

### ประเภทเงินในวอลเลต
- **เงินสด (Cash Balance)**: เงินที่สามารถถอนได้
- **เงินรางวัล (Reward Balance)**: เงินที่ได้จากการบรรลุเป้าหมาย
- **เงินที่ถูกล็อก (Locked Balance)**: เงินที่รอการปลดล็อก

### 3.1 การแปลงแต้มเป็นเงิน (Convert Points to Money)

**อัตราแลกเปลี่ยน:**
- **1,080 แต้ม = 1 บาท**

**วิธีทำ:**
```javascript
// API Call Example
POST /api/points/convert
{
  "points": 1080  // จำนวนแต้มที่ต้องการแปลง
}

// Response
{
  "success": true,
  "points_converted": 1080,
  "wallet_amount": 1.00,
  "new_points_balance": 0,
  "new_wallet_balance": 1.00
}
```

### 3.2 การฝากเงิน (Deposit Money)

**วิธีฝากเงิน:**
- ผ่านธนาคาร (Bank Transfer)
- ผ่านบัตรเครดิต (Credit Card)

**API Call:**
```javascript
POST /api/wallet/deposit
{
  "amount": 1000,
  "method": "bank_transfer",
  "reference": "REF123456",
  "description": "ฝากเงิน"
}
```

### 3.3 การถอนเงิน (Withdraw Money)

**เงื่อนไขการถอน:**
- ถอนขั้นต่ำ: **100 บาท**
- ถอนขั้นสูง: **50,000 บาท/ครั้ง**
- ถอนสูงสุด/วัน: **200,000 บาท**
- ถอนสูงสุด/เดือน: **1,000,000 บาท**
- ค่าธรรมเนียม: **0.5%** (ขั้นต่ำ 10 บาท)

**API Call:**
```javascript
POST /api/wallet/withdraw
{
  "amount": 500,
  "method": "bank_transfer",
  "bank_account": {
    "bank_name": "ธนาคารกรุงไทย",
    "account_number": "123-4-56789-0",
    "account_name": "สมชาย ใจดี"
  }
}
```

**สถานะการถอน:**
- `pending`: รอการอนุมัติจาก admin
- `completed`: ถอนเงินสำเร็จ
- `cancelled`: ถอนเงินถูกยกเลิก

### 3.4 การโอนเงิน (Transfer Money)

**API Call:**
```javascript
POST /api/wallet/transfer
{
  "to_user_id": 123,
  "amount": 100,
  "message": "ขอบคุณครับ"
}
```

## 4. ระบบ Gamification (Gamification System)

### 4.1 ระดับผู้ใช้ (User Levels)

**สูตรคำนวณ:**
```
Level = floor((Total Points / 100) ^ (2/3))
XP for Next Level = 100 × (Level + 1)^1.5
```

**ตัวอย่าง:**
- 0-99 แต้ม: Level 0
- 100-299 แต้ม: Level 1
- 300-599 แต้ม: Level 2
- 600-999 แต้ม: Level 3
- 1,000-1,499 แต้ม: Level 4
- และต่อเนื่อง...

### 4.2 ความสำเร็จ (Achievements)

#### ประเภทความสำเร็จ

**Points Achievements:**
- ได้แต้มครั้งแรก
- สะสม 1,000 แต้ม
- สะสม 10,000 แต้ม
- สะสม 100,000 แต้ม

**Action Achievements:**
- โพสต์ 10 ครั้ง
- ได้รับ 100 ไลค์
- คอมเมนต์ 50 ครั้ง

**Streak Achievements:**
- เข้า 3 วันต่อเนื่อง
- เข้า 7 วันต่อเนื่อง
- เข้า 30 วันต่อเนื่อง
- เข้า 100 วันต่อเนื่อง

**Social Achievements:**
- เพิ่มเพื่อน 10 คน
- เพิ่มเพื่อน 100 คน
- เพิ่มเพื่อน 1,000 คน

**Learning Achievements:**
- เข้าเรียนครั้งแรก
- ทำแบบทดสอบครั้งแรก
- ส่งงานครั้งแรก
- จบคอร์สครั้งแรก

### 4.3 ระบบ Badge

**ระดับความหายาก (Rarity Levels):**
- **Common** (สามัญ): 10-50 แต้ม
- **Uncommon** (ไม่สามัญ): 51-100 แต้ม
- **Rare** (หายาก): 101-200 แต้ม
- **Epic** (มหาศาล): 201-500 แต้ม
- **Legendary** (ตำนาน): 501+ แต้ม

### 4.4 ระบบ Leaderboard

**ประเภท Leaderboard:**
- **Points Leaderboard**: อันดับตามแต้มสะสมทั้งหมด
- **Weekly Leaderboard**: อันดับตามแต้มในสัปดาห์
- **Monthly Leaderboard**: อันดับตามแต้มในเดือน
- **Streak Leaderboard**: อันดับตาม streak ที่ยาวนานที่สุด
- **Achievement Leaderboard**: อันดับตามจำนวนความสำเร็จ

## 5. ระบบรางวัล (Rewards System)

### ประเภทรางวัล
- **Wallet Rewards**: บัตรกำนัล, เงินสด
- **Badge Rewards**: Badge พิเศษ
- **Feature Rewards**: ฟีเจอร์พิเศษ, ธีม
- **Discount Rewards**: ส่วนลด, โปรโมชัน

### วิธีการแลกรางวัล

**1. ดูรายการรางวัลที่แลกได้**
```javascript
GET /api/rewards
```

**2. แลกรางวัล**
```javascript
POST /api/rewards/redeem
{
  "reward_id": 1,
  "quantity": 1
}
```

**3. ดูรางวัลที่แลกแล้ว**
```javascript
GET /api/rewards/my
```

## 8. เคล็ดลับการสะสมแต้ม (Tips for Earning Points)

### 8.1 เคล็ดลับพื้นฐาน
1. **เข้าสู่ระบบทุกวัน** - รับแต้ม daily login และสร้าง streak
2. **โพสต์บ่อยๆ** - โพสต์พร้อมรูปภาพได้แต้มมากกว่า
3. **โต้ตอบกับผู้อื่น** - กดไลค์, คอมเมนต์, แชร์
4. **เรียนรู้ต่อเนื่อง** - เข้าเรียน, ทำแบบทดสอบ, ส่งงาน
5. **ดูโฆษณา** - แปลงเป็นเงิน wallet

### 8.2 เคล็ดลับขั้นสูง
1. **สร้างเนื้อหาที่น่าสนใจ** - เพื่อรับไลค์และการแชร์
2. **เข้าร่วมกิจกรรมพิเศษ** - รับแต้มโบนัส
3. **สร้างคอร์ส** - ได้แต้มและสร้างรายได้
4. **สร้างโพล** - ได้แต้มและสร้างการมีส่วนร่วม
5. **บริจาค** - ได้แต้มและช่วยเหลือผู้อื่น

### 8.3 กลยุทธ์การแปลงแต้ม
1. **แปลงเป็นเงินเมื่อมีแต้มเยอะ** - แปลงเป็นเงินทีละ 1,080 แต้มขึ้นไป
2. **เก็บแต้มสำหรับกิจกรรมพิเศษ** - บางกิจกรรมต้องใช้แต้ม
3. **แปลงเป็นเงินเพื่อถอน** - แปลงเป็นเงินเมื่อต้องการถอน

## 9. คำถามที่พบบ่อย (FAQ)

### Q1: แต้มหมดอายุไหม?
**A:** แต้มไม่หมดอายุ แต่บางโบนัสอาจมีเงื่อนไขเฉพาะ

### Q2: ถอนเงินใช้เวลานานแค่ไหน?
**A:** 1-3 วันทำการ ขึ้นอยู่กับการอนุมัติจาก admin

### Q3: สามารถโอนเงินให้ใครก็ได้ไหม?
**A:** โอนได้เฉพาะผู้ใช้ที่เป็นเพื่อนหรือในระบบเท่านั้น

### Q4: ถอนเงินขั้นต่ำเท่าไหร่?
**A:** 100 บาท

### Q5: ค่าธรรมเนียมถอนเงินเท่าไหร่?
**A:** 0.5% (ขั้นต่ำ 10 บาท)

### Q6: แต้มสามารถแปลงกลับเป็นเงินได้ไหม?
**A:** ไม่ได้ เมื่อแปลงแล้วจะไม่สามารถแปลงกลับได้

### Q7: ถอนเงินสูงสุดกี่บาทต่อวัน?
**A:** 200,000 บาท/วัน

### Q8: ถอนเงินสูงสุดกี่บาทต่อเดือน?
**A:** 1,000,000 บาท/เดือน

### Q9: ถ้าถอนเงินถูกปฏิเสธจะเกิดอะไรขึ้น?
**A:** เงินจะถูกคืนเข้า wallet อัตโนมัติ

### Q10: สามารถติดตามประวัติธุรกรรมได้ไหม?
**A:** ได้ สามารถดูได้ที่ `/api/points/transactions` และ `/api/wallet/transactions`
