## ส่วนที่ 1 — แท็บ "หน่วย"

เพิ่มใน `useElections.ts`: `listStations(a, e)` · `createStation(a, e, payload)` · `updateStation(a, e, s, payload)` · `deleteStation(a, e, s)`
(ของเดิมมี `openStation` `closeStation` `stationProgress` อยู่แล้ว — **ห้ามแก้ลายเซ็นสามตัวนี้** หน้าหน่วยเลือกตั้งใช้อยู่จริง)

| endpoint | หมายเหตุ |
|---|---|
| `GET .../elections/{e}/stations` | เพิ่มไว้แล้วใน E-S9a · คืนต่อหน่วย: `id` `name` `location` `is_open` `opened_at` `closed_at` `issued_count` `cast_count` |
| `POST .../elections/{e}/stations` | body: `name` (บังคับ ≤100) · `location` (ไม่บังคับ ≤150) |
| `PUT` / `DELETE .../stations/{s}` | แก้/ลบหน่วย |
| `POST .../stations/{s}/open` · `/close` | สิทธิ์ `elections.station` |

**สิ่งที่ต้องมีบนจอ:**
- ตาราง/การ์ดรายการหน่วย + ปุ่มสร้าง/แก้/ลบ (ถามยืนยันก่อนลบ)
- ปุ่มเปิด/ปิดหน่วย พร้อมสถานะปัจจุบันและเวลาเปิด/ปิด
  · เปิดหน่วยได้เฉพาะตอนการเลือกตั้งอยู่สถานะ `voting` — **disable พร้อมบอกเหตุผลล่วงหน้า** อย่ารอ 422
- 🔴 **ปุ่มคัดลอกลิงก์ของหน่วย** → `/academies/{name}/elections/{electionId}/station?station={stationId}`
  **นี่คือทางเข้าเดียวของหน้าหน่วยเลือกตั้ง** ถ้าไม่มีปุ่มนี้ กรรมการเข้าหน้างานไม่ได้เลย
  (หน้าหน่วยจะขึ้น "ไม่พบหน่วยเลือกตั้งนี้ กรุณาเปิดจากลิงก์ที่ผู้ดูแลแจกให้" ถ้า `?station=` ไม่ถูกต้อง)
- ตัวนับ `issued_count` / `cast_count` ต่อหน่วย

## ส่วนที่ 2 — แท็บ "ผล"

เพิ่มใน `useElections.ts`: `closeAndCount(a, e)` · `publishResults(a, e)` · `getResults(a, e)`

**พฤติกรรมตามสถานะ — ข้อนี้สำคัญที่สุดของแท็บนี้:**

| สถานะ | หน้าจอต้องแสดง |
|---|---|
| ก่อน `closed` | **turnout สดเท่านั้น** (`voted` / `total` / `percentage` / `by_grade_level` / `by_station`) |
| `voting` | ปุ่ม "ปิดหีบและนับคะแนน" (ถามยืนยัน · กดได้ครั้งเดียว) |
| `closed` | ผลที่นับแล้ว + ปุ่ม "ประกาศผล" (ถามยืนยัน) |
| `published` | ตารางผลถาวร |

🔴 **ห้ามแสดงคะแนนรายพรรคก่อนปิดหีบเด็ดขาด** — `turnout` ไม่มีข้อมูลรายพรรคโดยเจตนา
ห้ามไปดึงจากที่อื่นมาคำนวณเอง ห้ามเดา ห้ามประมาณ

**G3 — `GET /results` ตอบ 404 ถ้ายังไม่ประกาศ** ซึ่งชนกับ 404 ของ "ไม่มีการเลือกตั้งนี้"
→ **หน้าต้องเช็ค `election.status === 'published'` ก่อนแล้วค่อยเรียก** · ถ้าเผลอเจอ 404 ให้ขึ้น "ยังไม่ประกาศผล" ไม่ใช่ error ทั่วไป

**รูปร่างผล** (`election_results`): `party_id` · `votes` · `rank` · `is_winner` · `published_at` พร้อมความสัมพันธ์ `party`
- ต้องรองรับ **คะแนนเท่ากัน** — E-S7 คืนอันดับซ้ำได้ เช่น `1, 1, 3` และติดธง `is_winner` ได้มากกว่าหนึ่งพรรค
  **อย่าเรียงลำดับใหม่เองหรือทำให้อันดับไม่ซ้ำ** ให้แสดงตามที่ backend ส่งมา
- แถว "ไม่ประสงค์ลงคะแนน" มี `party_id` เป็น `null` · **ไม่มีอันดับและไม่ใช่ผู้ชนะ** ต้องแสดงแยกจากตารางอันดับให้ชัด

## ส่วนที่ 3 — แท็บ "บันทึก"

เพิ่มใน `useElections.ts`: `getAuditLog(a, e, page?)`

- `GET .../elections/{e}/audit-log` — timeline ของ 16 action พร้อมผู้ทำและเวลา
- 🔴 **paginate 15 แถวต่อหน้า** — วงจรเลือกตั้งหนึ่งรอบสร้าง log เกิน 15 แถวได้ง่าย ๆ
  ถ้าอ่านแค่หน้าแรกจะเห็นไม่ครบ **ต้องมี pagination จริง** (ตอนตรวจ E-S9a claude เกือบสรุปผิดเพราะข้อนี้)
- แสดงชื่อ action เป็นภาษาไทย — ดึงจาก `GET /api/academies/{a}/member-activity-logs/actions`
  (`MemberActivityLogController::getAvailableActions()` มี label ไทยของ election ครบ 16 ตัวอยู่แล้ว
  **อย่าเขียน mapping ภาษาไทยซ้ำในฝั่งหน้า** — ถ้าเรียก endpoint นั้นไม่สะดวก ให้บอกมา อย่าลอกตาราง)
  ตรวจ route จริงก่อนใช้ด้วย `php artisan route:list --json | Select-String activity`
- 🔴 **ข้อห้ามเรื่องบัตรลับ:** log ของ `election_ballot_issue` บอกได้แค่ว่า *ใครมารับบัตร*
  **ห้ามแสดง log นี้คู่กับผลคะแนนในจอเดียวกัน** และห้ามพยายามจับคู่ผู้ลงคะแนนกับตัวเลือกไม่ว่ากรณีใด

## กติกา mobile-first (บังคับ · ตรวจที่ 375px ก่อน)

- class ไม่มี prefix = มือถือ แล้วค่อย `sm:` `md:` `lg:` · ห้าม desktop-first
- ห้าม `hidden` ซ่อนข้อมูลสำคัญ · touch target ≥ 44px ทุกปุ่ม (เปิด/ปิดหน่วย · ปิดหีบ · ประกาศผล · คัดลอกลิงก์)
- ตารางหน่วย/ผล/บันทึก อยู่ในกล่อง `overflow-x-auto` ของตัวเอง · ห้ามทั้งหน้าเลื่อนแนวนอน
- แถวข้อความ `min-w-0 flex-1 break-words` · ฝั่งห้ามบีบ `flex-shrink-0 whitespace-nowrap`
- ใช้สกิล `hopeui-port` ดึงโครง markup จาก `hopa/` มาก่อน แล้วเขียน breakpoint ใหม่เป็น mobile-first
