## F2 — สรุปการล็อกบัญชีผู้มีสิทธิ์

### ปัญหาปัจจุบัน (ยืนยันด้วยการยิง HTTP จริงแล้ว)

`ElectionVoterRollTab.vue` มีการ์ดสรุป 10 ใบที่อ่านจาก `stats` (`GET /voter-roll/stats`)
แต่ endpoint นั้น **คืนมาแค่ 2 คีย์เท่านั้น**:

```json
{ "by_voter_type": [ { "voter_type": "staff", "total": 2 } ],
  "by_grade_level": [ { "grade_level": null, "total": 2 } ] }
```

ฟิลด์ที่การ์ดอ่านอยู่ตอนนี้ — `stats.total` · `stats.without_member_code` · `stats.without_student_card` ·
`stats.receipts_cast` · `stats.not_cast` — **ไม่มีอยู่จริงทั้งหมด → การ์ด 5 ใบขึ้น 0 ตลอด**
และการ์ด "ประถม"/"มัธยม" เทียบ `grade_level === 1` / `=== 2` ทั้งที่ค่าจริงในคอลัมน์นี้เป็น **สตริงอย่าง `ม.1`**
→ ขึ้น 0 อีก 2 ใบ · **รวม 7 จาก 10 ใบเป็นเลขปลอม**

### สิ่งที่ต้องทำ

ตัวเลขจริงทั้ง 10 ตัวมาจาก `POST /voter-roll/lock` อยู่แล้ว (ตัวแปร `counts` ในคอมโพเนนต์) คีย์เป๊ะ ๆ คือ:

| คีย์ | ความหมายที่ควรขึ้นบนจอ |
|---|---|
| `total` | ผู้มีสิทธิ์ทั้งหมด |
| `students` | นักเรียน |
| `staff` | บุคลากร |
| `without_member_code` | ไม่มีรหัสสมาชิก |
| `without_student_card` | นักเรียนที่ไม่มีบัตรนักเรียน |
| `duplicate_member_rows` | แถวสมาชิกซ้ำที่ถูกยุบรวม |
| `skipped_no_user_account` | ข้ามเพราะไม่มีบัญชีผู้ใช้ |
| `skipped_inactive_student` | ข้ามเพราะสถานะนักเรียนไม่ active |
| `skipped_other_level` | ข้ามเพราะอยู่คนละระดับกับการเลือกตั้งนี้ |
| `staff_without_level` | บุคลากรที่ยังไม่ได้ระบุระดับ |

1. **การ์ดสรุปทั้งหมดต้องอ่านจาก `counts` ไม่ใช่ `stats`** — แสดงครบทั้ง 10 คีย์
2. **ถ้ายังไม่เคยกดล็อกในเซสชันนี้ `counts` จะเป็น null** → ต้องมีทางแสดงตัวเลขล่าสุดด้วย เลือกทางใดทางหนึ่ง:
   - เก็บผลล็อกล่าสุดไว้ฝั่ง backend แล้วส่งกลับมา **(ถ้าเลือกทางนี้ต้องบอกก่อนว่าจะเก็บที่ไหน อย่าเดาสร้างคอลัมน์ใหม่เอง)** หรือ
   - **ทางที่แนะนำ:** ซ่อนการ์ดไว้จนกว่าจะมี `counts` แล้วขึ้นข้อความว่า "กดล็อกบัญชีเพื่อดูสรุป"
     พร้อมแสดง `voter_roll_locked_at` ว่าล็อกล่าสุดเมื่อไร
3. **การ์ดที่มาจาก `stats` ให้เหลือเฉพาะที่ endpoint ส่งจริง** — แจกแจงตาม `by_voter_type` และ `by_grade_level`
   (ค่า `grade_level` เป็นสตริง ให้แสดงตามที่ได้มา อย่าเทียบกับตัวเลข)
4. **คำเตือนสองข้อต้องใช้ค่าจาก `counts`**:
   - `counts.staff_without_level > 0` → ข้อความต้องมีตัวเลข **`{{ counts.staff_without_level }}`** ไม่ใช่เลขคงที่
     เนื้อความ: บุคลากร N คนยังไม่ได้ระบุระดับ — ถ้าล็อกบัญชีตอนนี้ การเลือกตั้งที่แยกประถม/มัธยมจะไม่มีบุคลากรลงคะแนนเลย
     พร้อมปุ่มกรองไปที่บุคลากรที่ยังไม่มีระดับ (ใช้ filter `voter_type=staff` ที่มีอยู่)
   - `counts.without_student_card > 0` → ข้อความต้องมีตัวเลข **`{{ counts.without_student_card }}`**
     เนื้อความ: นักเรียน N คนไม่มีบัตรนักเรียน — ที่หน่วยเลือกตั้งต้องใช้ช่องพิมพ์รหัสสมาชิกแทนการสแกน
     พร้อมปุ่มกรอง `missing=student_card`
5. บนมือถือ (375px) การ์ด 10 ใบให้เรียง 2 คอลัมน์แล้วค่อยขยายที่ `sm:`/`lg:` · touch target ≥ 44px

## F7 — งานที่เหลือของแท็บพรรค

- **ช่องกรอกเบอร์ตอนอนุมัติ** — ปล่อยว่าง = ให้ระบบหาเบอร์ว่างให้ (ยิงจริงแล้ว: ส่ง `number: null` ได้เบอร์ 1) ·
  กรอกเอง = ส่งเลขนั้นไป · ถ้าเบอร์ซ้ำ backend ตอบ 422 พร้อมข้อความไทย ให้แสดงข้อความนั้นตรง ๆ
- **แสดง `review_note` และ `reviewed_at`** ของพรรคที่ถูกปฏิเสธ (payload มีสองคีย์นี้อยู่แล้ว)
- ⚠️ **ห้ามเปลี่ยนพฤติกรรมเบอร์ของพรรคที่ถอนตัว** — ยังเป็นข้อค้างที่เจ้าของโปรเจคต้องตัดสิน (§10 E-S3)
