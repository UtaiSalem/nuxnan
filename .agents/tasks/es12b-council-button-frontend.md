## เป้าหมาย

ให้ กกต. กดตั้งคณะกรรมการสภานักเรียนจากหน้าผลคะแนนได้ และ**อ่านออกว่าทำไมกดไม่ได้**เมื่อระบบปฏิเสธ

## สัญญา API ที่ล็อกแล้ว (shard a เขียนตามอันนี้ ห้ามเดาเอง)

```
POST /api/academies/{academy}/elections/{election}/council
body: { "name": "…" }   // optional
```

**สามกรณีที่ถูกปฏิเสธ ทั้งหมดตอบ 422 พร้อม `message` ภาษาไทย:**

| กรณี | สิ่งที่มากับ response |
|---|---|
| ยังประกาศผลไม่เสร็จ | `message` |
| คะแนนเสมอกันจนมีผู้ชนะหลายพรรค | `message` + ชื่อพรรคที่เสมอกันและคะแนน |
| ตั้งไปแล้ว | `message` + `group_id` + `group_name` |

## งานที่ต้องทำ (3 ไฟล์)

### 1. `ui/constants/academyGroupTypes.ts` — เพิ่ม type ที่ 10

ค่าที่ล็อกไว้ **ต้องตรงกับฝั่ง PHP เป๊ะทุกฟิลด์**:

```ts
{ key: 'student_council', label: 'สภานักเรียน', labelEn: 'Student Council', icon: 'heroicons:megaphone', color: 'pink', order: 10 }
```

**ห้ามแก้ 9 ตัวเดิม** · สังเกตว่าไฟล์นี้จัดคอลัมน์ให้ตรงกันด้วยช่องว่าง — เขียนให้เข้ากับของเดิม
· **`color` ต้องเป็นค่าที่มีอยู่ใน union type `AcademyGroupTypeMeta['color']` อยู่แล้ว** (`pink` มีอยู่แล้ว ไม่ต้องแก้ type)

### 2. `ui/composables/useElections.ts` — เพิ่มฟังก์ชันเรียก endpoint

เขียนตามรูปแบบเดิมของไฟล์ (ใช้ `api.call` กับ `electionsBase(a)`)
**อย่าลืมเพิ่มชื่อฟังก์ชันลงใน object ที่ `return` ท้าย composable** ไม่งั้น import ไปใช้ไม่ได้
· **ห้ามแตะฟังก์ชันอื่นในไฟล์นี้**

### 3. `ui/components/academy/elections/ElectionResultsTab.vue` — ปุ่ม + ข้อความ

ไฟล์นี้ 100 บรรทัด มีปุ่ม "ปิดหีบและนับคะแนน" กับ "ประกาศผล" อยู่แล้ว ใช้เป็นแบบได้เลย

- ปุ่มใหม่แสดงเมื่อ **`election.status === 'published'` และ `canManage`**
- กดแล้วยืนยันก่อน (ไฟล์นี้ใช้ `confirm()` อยู่แล้วสำหรับสองปุ่มเดิม — ใช้ให้เหมือนกัน)
- **สำเร็จ** → แสดงกล่องเขียวพร้อมลิงก์ไปหน้ากลุ่ม
  route คือ `/academies/{name}/groups/{groupId}` · **component นี้รับมาแต่ `academyId` ไม่มี name**
  → ดึงจาก `useRoute().params.name`
- **ถูกปฏิเสธ** → แสดง `message` จาก response · ถ้าเป็นกรณี "ตั้งไปแล้ว" ให้ทำลิงก์ไป `group_id` ที่ได้มาด้วย
- **ห้ามกลืน error เงียบ ๆ** — สามกรณีข้างบนคือสิ่งที่คนใช้ต้องอ่านออกว่าเกิดอะไรขึ้น

## 🔴 กติกา mobile-first (บังคับ)

- **class ที่ไม่มี prefix = สไตล์ของมือถือ** แล้วค่อยใช้ `sm:` `md:` `lg:` เพิ่มเมื่อจอกว้างขึ้น
  ห้ามเขียนแบบ desktop-first เช่น `flex-row md:flex-col` — ต้องเป็น `flex-col md:flex-row`
- **ห้ามใช้ `hidden` ซ่อนข้อมูลสำคัญบนมือถือ** โดยเฉพาะข้อความบอกเหตุผลที่ถูกปฏิเสธ
- **touch target ขั้นต่ำ 44px** (`min-h-[44px]`) — ปุ่มเดิมในไฟล์นี้ใช้ `min-h-[44px]` อยู่แล้ว ทำให้เหมือนกัน
- แถวที่เป็น flex: ฝั่งที่ห้ามถูกบีบใส่ `flex-shrink-0` + `whitespace-nowrap`,
  ฝั่งข้อความใส่ `min-w-0 flex-1` + `break-words` (ภาษาไทยไม่มีช่องว่าง จะแตกแนวตั้งถ้าโดนบีบ)
- ตารางผลคะแนนในไฟล์นี้อยู่ในกล่อง `overflow-x-auto` อยู่แล้ว — **ห้ามทำให้ทั้งหน้าเลื่อนแนวนอน**
- padding/ตัวอักษรไล่เล็กไปใหญ่ · **ตรวจจริงที่ 375px ก่อนเสมอ**
