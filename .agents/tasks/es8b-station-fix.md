## ขอบเขตงาน (ทำเท่านี้ ห้ามเกิน)

### ส่วนที่ 1 — Backend (`api/nuxnanravel/`)

**1.1 `ElectionStationService::lookup()` — เติมฟิลด์ที่หน้าจอต้องใช้**

คืนค่าเพิ่ม/แก้เป็น (คงคีย์เดิมไว้ทั้งหมดเพื่อไม่ให้ของเดิมพัง):

| คีย์ | ค่า |
|---|---|
| `user_id` | เดิม |
| `name` | เดิม |
| `photo` | **เปลี่ยนลำดับแหล่งที่มา** — ดู 1.2 |
| `classroom` | เดิม |
| `grade_level` | **ใหม่** — `$voter?->grade_level` |
| `status` | เดิม (`eligible` / `already_voted` / `not_on_roll`) |
| `status_label` | เดิม |

**1.2 แหล่งรูปผู้มาใช้สิทธิ์ — ต้องเอาจากบัตรนักเรียนก่อน**

ตัวเลขจริงของโรงเรียนนี้: `users.profile_photo_path` มีรูปแค่ **344/2,613 คน (13%)** แต่ `student_cards.profile_image` มี **1,696/2,647 ใบ (64%)**
→ `photo` ต้องเลือกตามลำดับ: `student_cards.profile_image` (ของ `student_id` เดียวกัน, `academy_id` ตรงกัน, `is_active_flag = 1`) → ถ้าไม่มีค่อย fallback `users.profile_photo_path` → ถ้าไม่มีคืน `null`

🔴 **แก้ที่ `ElectionStationService::lookup()` เท่านั้น ห้ามแก้ `StudentIdentifierResolver`** — ตัวหลังใช้ร่วมกับระบบเช็คชื่อ (เมนู #18/#26) การเปลี่ยนรูปคืนค่าจะลามข้ามเมนู

**1.3 `ElectionStationController::progress()` — เติมสิ่งที่จอต้องแสดง**

คืนเพิ่ม: `name` (ชื่อหน่วย) · `is_open` (bool) · `location`
คงคีย์เดิม `issued` `cast` `remaining` ไว้ (มีเทสต์อ้างอยู่ — ห้ามเปลี่ยนชื่อคีย์เดิม)

**1.4 `ElectionStationService::issue()` — คืน `ballot_ttl_seconds`**

เพิ่มคีย์ `ballot_ttl_seconds` = `$e->ballot_ttl_seconds ?? 180` (ค่าเดียวกับที่ใช้คำนวณ `token_expires_at` จริง) เพื่อให้ตัวนับถอยหลังบนจอตรงกับอายุบัตรจริง

**1.5 เทสต์**

เพิ่มเทสต์ในชุด `Election` ที่ยืนยันว่า:
- `lookup` คืนคีย์ครบ 7 ตัวตาม 1.1 และ `grade_level` มีค่าจริงเมื่อผู้มีสิทธิ์เป็นนักเรียนที่มีชั้น
- `photo` เลือกรูปจากบัตรนักเรียนเมื่อมีทั้งสองแหล่ง และ fallback ถูกต้องเมื่อมีแค่แหล่งเดียว/ไม่มีเลย
- `progress` คืน `name` + `is_open` ตรงกับสถานะจริงหลัง `open()` และหลัง `close()`
- `issue` คืน `ballot_ttl_seconds` ตรงกับค่าใน election

### ส่วนที่ 2 — Frontend (`ui/pages/academies/[name]/elections/[id]/station.vue`)

**2.1 จัดชื่อฟิลด์ให้ตรงสัญญาใหม่**

| ที่ผิดตอนนี้ | ต้องเป็น |
|---|---|
| `voter.status_code` | `voter.status` |
| `voter.photo_url` | `voter.photo` (แปลงเป็น URL ด้วย `useAvatar()` / `${apiBase}/storage/...` ตามที่หน้าอื่นในเรพทำ) |
| `voter.classroom_name` | `voter.classroom` (ยัง fallback `classroom_name` ได้ เพราะแถวจากช่องค้นหาชื่อใช้คีย์นั้น) |
| `station.issued_count` / `cast_count` | `station.issued` / `station.cast` |
| ค่าคงที่ 180 | `data.ballot_ttl_seconds` |

⚠️ **ผลค้นหาด้วยชื่อคืนแถว `election_voters` ตรง ๆ** (คีย์: `user_id` `display_name` `grade_level` `classroom_name` `member_code` — **ไม่มี `status` และไม่มีรูป**)
→ เมื่อกรรมการเลือกคนจากผลค้นหา **ต้องยิง `lookup` ด้วย `member_code` ของคนนั้นต่อทันที** เพื่อให้ได้สถานะ+รูปมาก่อนออกบัตร ห้ามเอาแถวค้นหาไปตั้งเป็น `voter` ตรง ๆ

**2.2 เปิด/ปิดหน่วย**

- เพิ่มปุ่ม **"เปิดหน่วย"** เมื่อ `is_open === false` และปุ่ม **"ปิดหน่วย"** (ถามยืนยันก่อน) เมื่อเปิดอยู่ — เรียก `openStation()` / `closeStation()` ที่มีอยู่แล้วใน `useElections.ts`
- backend โยน 422 พร้อมข้อความไทยถ้าการเลือกตั้งยังไม่อยู่สถานะ `voting` → แสดงข้อความนั้นตรง ๆ

**2.3 เลือกหน่วย**

ตอนนี้ `stationId` = `route.query.station || 1` ซึ่งถ้าหน่วย id 1 เป็นของการเลือกตั้งอื่นจะได้ 404 เงียบ ๆ
→ ถ้าไม่มี `?station=` ใน URL หรือเรียก `progress` แล้วได้ 404 **ต้องขึ้นหน้าจอบอกให้ชัดว่า "ไม่พบหน่วยเลือกตั้งนี้ กรุณาเปิดจากลิงก์ที่แอดมินแจก"** ห้ามปล่อยจอว่าง
(หน้าแอดมินที่แจกลิงก์ `?station=` เป็นงานของ E-S9 — งานนี้แค่ต้องไม่พังเงียบ)

**2.4 ล้างสถานะให้หมดหลังลงคะแนน**

หลัง `cast` สำเร็จและเด้งกลับหน้าสแกน ต้องล้าง `code` `query` `searchResults` `ballotParties` `token` `error` ด้วย
**ห้ามให้รหัส/ชื่อของคนก่อนหน้าค้างบนจอให้คนถัดไปเห็น**

**2.5 เก็บกวาด**

- ลบ `const toast = useToast()` ที่ไม่ได้ใช้
- แก้ปุ่มสแกนให้เรียก `startScanning()` เฉย ๆ (ฟังก์ชันไม่รับพารามิเตอร์)
- ย้ายรายการผลค้นหาเข้าไปอยู่ **ในการ์ดยืนยันตัวตนภายใน `<main>`** (ตอนนี้อยู่นอก `<main>` เหนือ header)
- แตกไฟล์ใหม่ให้อ่านได้: หนึ่ง statement ต่อบรรทัด (ตอนนี้บางบรรทัดยาว 2,000+ ตัวอักษร) และแยก component ย่อยได้ตามเหมาะสม — **ตั้งชื่อ component ยาวและไม่ซ้ำ** (เช่น `ElectionStationVoterCard`) เพราะชื่อสั้นทำให้ auto-import ของ Nuxt หาไม่เจอแล้ว component หายเงียบ ๆ

### ส่วนที่ 3 — ห้ามแก้ให้เสีย (ของเดิมที่ถูกแล้ว)

- โหมด `ballot` **ห้ามแสดงชื่อ/รูปผู้ลงคะแนนบนจอ** (กันคนข้างหลังเห็นว่าใครเลือกอะไร)
- หน้า `done` **ห้ามทวนว่าเลือกเบอร์อะไร**
- abstain ส่ง `party_id: null`
- `onUnmounted` ปิดกล้อง + เคลียร์ timer
- **ห้ามเพิ่ม log ที่ผูกตัวผู้ลงคะแนนกับตัวเลือก** ไม่ว่ากรณีใด (บัตรลับ — `$actor` ใน `cast` ถูกจงใจไม่ใช้ มีคอมเมนต์กำกับไว้แล้ว)

## กติกา mobile-first (บังคับ — งานนี้อยู่ใน `ui/`)

- class ที่ไม่มี prefix = มือถือ แล้วค่อย `sm:` `md:` `lg:` · **ห้าม desktop-first**
- ห้าม `hidden` ซ่อนข้อมูลสำคัญบนมือถือ — จัดวางใหม่แทน
- touch target ≥ 44px — ปุ่มออกบัตร/เลือกพรรค/ยืนยัน ต้องกดโดนขณะถือเดิน
- แถว flex: ฝั่งห้ามบีบ `flex-shrink-0 whitespace-nowrap` · ฝั่งข้อความ `min-w-0 flex-1 break-words` (ชื่อไทยไม่มีช่องว่าง จะแตกแนวตั้งถ้าโดนบีบ)
- ห้ามให้ทั้งหน้าเลื่อนแนวนอน
- **ตรวจที่ 375px ก่อน** แล้วค่อย 768 / 1280

## Acceptance criteria

1. `./vendor/bin/pint` ผ่าน
2. `php artisan test --filter Election` เขียวทั้งชุด — **ฐานเดิม 119 เทสต์ ห้ามลดลง** และต้องมีเทสต์ใหม่ตามข้อ 1.5
3. **พิสูจน์กับ DB จริงใน `DB::beginTransaction()` … `rollBack()`** (ตาราง election ทุกตัวตอนนี้ 0 แถว ต้องกลับเป็น 0 แถวเมื่อจบ):
   สร้าง election `voting` + พรรคอนุมัติ + หน่วย + ผู้มีสิทธิ์ที่เป็นนักเรียนซึ่ง**มีบัตรนักเรียนพร้อมรูป** → เรียก `lookup` แล้ว **print คีย์ที่ได้จริงออกมา** ต้องครบ 7 คีย์ และ `photo` ต้องเป็นรูปจากบัตร → `open` แล้ว `progress` ต้องได้ `is_open = true` + `name` ตรง → `issue` ต้องมี `ballot_ttl_seconds`
4. เทียบทีละคีย์ว่าทุกฟิลด์ที่ `station.vue` อ่าน **มีอยู่จริงใน payload** — นี่คือข้อที่ E-S8 ตกรอบแรก **build เขียวไม่ใช่หลักฐาน** เพราะฟิลด์ที่ผิดเป็น `any` ทั้งหมด
5. รายงานกลับต้องแนบ **output จริง** ของข้อ 2 และข้อ 3 (ไม่ใช่คำบรรยาย)
